How to get your free Google Cloud Client ID & Secret (takes 2 minutes, 100% free):

  1. Open the Google Cloud Console and click Enable for YouTube Data API v3.
  2. Go to APIs & Services → Credentials, click Create Credentials → OAuth client ID (Application type: Web application).
  3. Under Authorized redirect URIs, add: https://YOUR-DOMAIN/api/oauth/google/callback (and for the login button: https://YOUR-DOMAIN/api/auth/google/callback).
  4. Copy your Client ID and Client Secret below and click Save & Connect.
